# Arquitetura de Objetos

**Roteiros práticos de estudo para a disciplina de Arquitetura de Objetos**, ministrada pelo professor **Eduardo Felipe Zambom Santana**.

Acompanhe a construção dos programas desenvolvidos em aula, passo a passo. Cada roteiro indica o que escrever, apresenta os novos conceitos no momento em que são necessários e mostra o resultado esperado de cada execução.

## Como estudar

- **Siga a sequência:** cada aula dá continuidade ao programa anterior, salvo quando indicado.
- **Escreva e execute:** digite o código por conta própria e teste cada etapa.
- **Faça previsões:** tente responder às atividades antes de revelar as soluções.
- **Pratique:** ao final de cada aula, resolva os exercícios complementares.

Consulte a [Referência rápida](referencia/java.md) e o [Glossário](referencia/glossario.md) sempre que precisar revisar um comando ou conceito.
